# PESOK — Telegram Mini App магазин

Первая версия: каталог по городам, варианты товара в граммах, тестовые заказы, админ-панель для управления товарами и карьерными точками. Реальные платежи не подключены.

## Render
Build: `pip install -r requirements.txt`
Start: `uvicorn main:app --host 0.0.0.0 --port $PORT`
Задайте секретную переменную `ADMIN_PASSWORD`.

Стартовый город — Невьянск; товары — «ОЛЬГА» и «МИША»; варианты — 0,5 / 1 / 2 / 3 грамма. Заказы сохраняются со статусом `demo_pending`, деньги не списываются.

ВНИМАНИЕ: бесплатный Render может засыпать, а SQLite без постоянного диска не гарантирует сохранность данных при пересоздании сервиса. Перед реальными заказами подключить постоянную БД. Telegram initData пока не используется для авторизации, а платёжная интеграция намеренно отложена.
